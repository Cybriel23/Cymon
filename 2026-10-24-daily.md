## 1. Risk Watch

### 1.1 PHP2Shell: critical PHP RCE, exploitation reported (ONGOING, follow-up)
Two flaws, **CVE-2026-109618** and **CVE-2026-109619** (reported **9.2**), allow unauthenticated RCE. Fixed in **8.5.12, 8.4.27, 8.3.36, 8.2.35**; 8.1 and older get no upstream fix. Vercel, Tanium and watchTowr report exploitation attempts and public exploits; The Hacker News reports failed attempts to recruit systems into a Mirai variant (Potassium). I found no KEV listing as of the last checked update (21 Oct). One repository audit claims the underlying bug does not exist in released PHP and that NVD had no record of the IDs; most vendors treat it as real, so verify against php.net and NVD. Updating app code or plugins does not fix it; the PHP runtime must be upgraded.
**Action:** Inventory all PHP runtimes (containers, shared hosting, CMS), upgrade to the fixed point releases, isolate EOL branches, add WAF rules, and review web logs since 17 Oct for odd requests and new files in web roots.
Sources: [BleepingComputer](https://bleepingcomputer.com/news/security/php-ships-emergency-patches-for-critical-php2shell-flaws) · [Tanium](https://www.tanium.com/blog/php2shell-responding-to-cve-2026-109618-and-cve-2026-109619) · [Vercel](https://vercel.com/kb/bulletin/php2shell-security-bulletin) · [Canadian Cyber Centre](https://cyber.gc.ca/fr/alertes-avis/al26-026-vulnerabilites-critiques-touchant-php-cve-2026-109618-cve-2026-109619)

### 1.2 Ivanti Connect Secure zero-day chain, escalation still unpatched (ONGOING, follow-up)
Volexity's **UTA0576** chains auth bypass and RCE (**CVE-2026-104935**, fixed in **22.8R2.5, 25.1.1.2, 25.1.3.0, 25.1.3.1**) with a privilege-escalation flaw to reach root on patched appliances. Searches today again show no CVE or fix for the third link ("weeks away"). Exploitation started 1 to 3 Oct; the actor re-exploits per command, tampers with logs and evades Ivanti's Integrity Checker.
**Action:** Apply fixed builds, restrict portal exposure, preserve external logs, rotate secrets and certificates held on the appliance, and check Ivanti's advisory daily.
Sources: [BleepingComputer](https://bleepingcomputer.com/news/security/ivanti-warns-of-connect-secure-zero-day-exploited-in-attacks) · [The Hacker News](https://thehackernews.com/2026/10/attacker-chains-three-ivanti-connect.html) · [iTnews](https://itnews.com.au/news/attackers-chain-three-ivanti-vpn-zero-days-for-root-access-629621)

### 1.3 LiteLLM 1.107.0 malicious release (NEW, DEVELOPING)
Socket and Wiz report that LiteLLM **1.107.0** (PyPI and Docker, uploaded **21 Oct**) contains malicious Python startup files that harvest cloud credentials, private keys, browser data and AI-tool auth files. LiteLLM says the release went out through three engineers' GitHub accounts, apparently via stolen GitHub CLI OAuth tokens; root cause is under investigation. Socket notes provenance pointing to a one-hyphen lookalike repo (Berri-AI/litellm). Last known safe version: **1.106.2**. This is separate from the March 2026 compromise (1.82.7/1.82.8, attributed by CSA to TeamPCP).
**Action:** Pin to 1.106.2 or earlier, find hosts, containers and CI runners that installed 1.107.0, treat all reachable credentials as exposed and rotate them, and review Python startup (.pth) files.
Sources: [Socket](https://socket.dev/blog/litellm-compromise) · [Wiz](https://www.wiz.io/blog/litellm-compromised-steals-credentials) · [The Hacker News](https://thehackernews.com/2026/10/litellm-compromised-in-supply-chain.html)

### 1.4 Cisco Secure Email Gateway CVE-2026-76519 exploited (ONGOING)
Path traversal in the Advanced Malware Protection feature (**CVSS 9.8**): a crafted attachment writes files and runs commands as root, unauthenticated. Requires File Reputation enabled on a mail policy and Content Scanner Tools older than **25.3.0.5525**. Cisco published IOCs and contacted affected Secure Email Cloud customers; CISA added it to KEV (deadline reported 17 Oct). Second SEG flaw exploited since mid-September (after CVE-2026-76461). Sources differ on whether this was a zero-day or patched in September (AsyncOS **15.5.5-014 / 16.5.0-780**).
**Action:** Update Content Scanner Tools to 25.3.0.5525+ and AsyncOS, check Cisco's IOCs, and treat compromised appliances as exposing cluster SSH keys.
Sources: [SecurityWeek](https://www.securityweek.com/cisco-warns-of-exploited-secure-email-gateway-vulnerability/) · [BleepingComputer](https://bleepingcomputer.com/news/security/cisco-patches-actively-exploited-secure-email-gateway-zero-day) · [The Hacker News](https://thehackernews.com/2026/10/cisco-warns-of-active-attacks.html)

### 1.5 Edge credential abuse: k0t firewall/VPN haul and GlobalProtect CVE-2026-0257 (ONGOING)
Group-IB and NyxLab say actor **k0t** obtained **70,000+** credentials from enterprise firewalls and VPNs, with assessed ties to Qilin and The Gentlemen. Unit 42 (updated 19 Oct) and Arctic Wolf report Qilin and INC use **CVE-2026-0257** (GlobalProtect auth bypass when authentication-override cookies are enabled with certain certificate settings; fixed 13 May; in KEV) for VPN access, with sessions from "kali" hostnames. FortiBleed activity (FBI advisory) continues per yesterday.
**Action:** Patch PAN-OS, disable authentication-override cookies where possible, force password and API-key rotation on VPN and firewall admin accounts, enforce phishing-resistant MFA, and alert on VPN sessions from hostname "kali".
Sources: [The Hacker News](https://thehackernews.com/2026/10/hackers-breach-enterprise-firewalls-and.html) · [Arctic Wolf](https://arcticwolf.com/resources/blog/exploitation-of-cve-2026-0257-leads-to-qilin-ransomware/) · [Unit 42](https://unit42.paloaltonetworks.com/active-exploitation-of-pan-os-cve-2026-0257/)
