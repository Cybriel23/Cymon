# Daily Cyber Threat Intelligence Briefing
Wednesday, 11 November 2026 · Coverage: 06:00 UTC 10 Nov – 06:15 UTC 11 Nov 2026 and follow-ups on tracked topics

## Executive Summary
Patch Tuesday made this a very heavy day. Microsoft, SAP, Adobe, Fortinet and Ivanti all released fixes, and CISA added **six** flaws to KEV in one day. Four things need attention today. **First**, attackers are exploiting a Microsoft Outlook zero-day, **CVE-2026-124194**, to steal NTLMv2 hashes. It is in KEV (due **24 Nov**). The same release also fixes zero-click 9.8 bugs in Windows Search (reachable through Exchange) and LDAP. **Second**, Barracuda confirms attacks on its Email Security Gateway that chain **CVE-2026-116606** and **CVE-2026-111560** to get root. CISA set a very short deadline of **13 Nov**. **Third**, attackers are using the Xen Orchestra authentication bypass **VSA-2026-062** to take over XCP-ng virtualization hosts. **Fourth**, Fortinet (FortiManager/FortiAnalyzer, up to CVSS **9.8**) and SAP (four CVSS **10.0** flaws: ICM2SHELL, PROXYGATE, SAML2) published pre-authentication RCE bugs. Neither vendor reports exploitation yet, but both product lines have been heavily targeted after past disclosures. Also still open: N-able N-central remains offline with no hotfix confirmed, and the 9 Nov KEV batch (SSHole, GPUStack, FreeSWITCH, Faspex) is due **tomorrow, 12 Nov**. **Watch this week for:** the N-central hotfix, LNbits patches, whether Apple fixes the public iOS "worse_query" sandbox escape, a Git for Windows build with the CVE-2026-111760 fix, and new exploitation of the SAP and Fortinet bugs as patch-diffing starts.

## 1. Risk Watch

### 1.1 Microsoft November Patch Tuesday: Outlook zero-day CVE-2026-124194 exploited, plus zero-click 9.8s (NEW)
- **The release:** Microsoft lists **1,094** CVEs. BleepingComputer counts **1,235** because it includes Edge and other non-Microsoft entries. This is the second month in a row above 1,000.
- **Zero-day CVE-2026-124194 (Outlook, CVSS 6.5, in KEV):** opening a crafted message file makes Outlook connect to an attacker-controlled location without the usual external-content warning, which leaks the user's **NTLMv2** hash. The hash can be cracked offline or relayed. Microsoft gave no detail on the attackers. ZDI warns that the "spoofing" label understates the impact.
- **Other priorities:**
  - **CVE-2026-116928** (Windows Search, 9.8): zero-click, reachable through Exchange attachment indexing.
  - **CVE-2026-119958** (LDAP, 9.8): zero-click, puts domain controllers at risk.
  - **CVE-2026-112967** (Xbox Live Networking, 9.8).
  - Critical RCEs in Exchange (**CVE-2026-118207**) and AD DS (**CVE-2026-118146**).
  - ZDI counts **30** network-reachable CVEs that need no authentication or user interaction.

**Action:**
- Deploy the Office/Outlook updates first.
- Block outbound SMB (TCP 445) and WebDAV to the internet.
- Add high-value users to the Protected Users group, or restrict NTLM where you can.
- Hunt for Outlook processes connecting to external UNC/WebDAV paths since late October.
- Patch Exchange servers and domain controllers next.
- Windows 11 KB5132061/KB5131087 and Windows 10 ESU KB5131096 carry the fixes.

Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-november-2026-patch-tuesday-fixes-1-235-flaws-outlook-zero-day/), [The Register](https://www.theregister.com/security/2026/11/10/november-patch-tuesday-boasts-over-1000-bugs-but-only-one-zero-day-so-far/5308946), [CyberScoop](https://cyberscoop.com/microsoft-patch-tuesday-november-2026/), [Cyber Security News](https://cybersecuritynews.com/outlook-0-day-vulnerability/), [CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)

### 1.2 Barracuda Email Security Gateway: root-level chain now exploited, KEV due 13 Nov (NEW, ONGOING)
- **Exploitation:** in a late 9 Nov advisory update, Barracuda says it has seen exploitation affecting "a small number of organizations." It did not say how many.
- **The chain:**
  - **CVE-2026-116606** (CVSS 9.3): a pre-authentication authorization bypass that can change the appliance's global configuration. It needs access to the admin UI.
  - **CVE-2026-111560**: unauthenticated OS command injection that runs as root. It also affects Load Balancer ADC, WAF, WAF Control Center, Message Archiver and Web Security Gateway.
- **Fixes:** released about a week ago.
  - ESG: BNSF-40425 (9.4.017+) and BNSF-40430 (<9.4.017).
  - ADC/WAF: BNADC-16586. BMA: BNMA-32468. WCC: BNWF-60060. WSG: BNYF-24789.
- **KEV deadline:** CISA's three-day window (**13 Nov**) shows how urgent it considers this.
- **History:** Barracuda ESG was the target of UNC4841's 2023 campaign (SeaSpy, Saltwater). In that campaign, affected appliances had to be replaced, not just patched.

**Action:**
- Check that the patches applied. Auto-update may not have run.
- Restrict the admin UI to internal management networks.
- Look for configuration changes and new processes or cron entries on appliances from **early November** onward.
- Barracuda has not released IOCs, so ask support if anything looks wrong.

Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-exploit-barracuda-email-security-gateway-flaws-to-get-root-access/), [The Register](https://www.theregister.com/security/2026/11/10/barracudas-email-security-gateways-bitten-by-make-me-root-vulns/5308883), [Cyber Security News](https://cybersecuritynews.com/barracuda-email-gateway-flaws/), [CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)

### 1.3 Xen Orchestra VSA-2026-062: authentication bypass exploited to hijack XCP-ng hosts (NEW)
- **The flaw:** Vates says a crafted cookie, `authenticationToken=j:%7B%7D`, is parsed into an empty object. The token lookup then matches the first unexpired token, giving the attacker **admin** rights. No CVE has been assigned yet.
- **Fixed versions:** **Xen Orchestra 6.9.1** (stable) and **6.10.0** (latest); **xo-server 5.211.2 / 5.213.1**.
- **Exploitation:** confirmed in the wild. It is not known when it started or whether it was used as a zero-day.
- **Infrastructure:** **91.211.251[.]112:8001** (flagged on VirusTotal as a RedLine Stealer C2) and an onion service, `ustar3rqxgnskzgnwkgpofgtvxevm6cx3lxdbwt4mndtveqyaohid[.]onion:3333`.
- **Why it matters:** an attacker who controls the hypervisor manager controls every VM on it, a common precursor to ransomware.

**Action:**
- Upgrade now and take XO off the internet.
- Block the empty-token cookie in a WAF or reverse proxy.
- Hunt for:
  - requests containing `authenticationToken=j:{}` or `j:%7B%7D`;
  - a VM named `pivot2`;
  - VMs with `hvm_serial: file`;
  - `/etc/cron.d/zz-ustar*`, `/.ustar5` or `/.ustar6`.
- If you find any of these, rotate all XO and host secrets.

Sources: [The Hacker News](https://thehackernews.com/2026/11/hackers-exploit-critical-xen-orchestra.html), [BleepingComputer](https://www.bleepingcomputer.com/news/security/critical-xen-orchestra-auth-bypass-flaw-exploited-to-hijack-vm-servers/)

### 1.4 Fortinet: pre-auth RCE in FortiManager/FortiAnalyzer, plus FortiOS routing flaws (NEW)
Fortinet published a large batch of advisories on **10 Nov**. None are marked exploited yet, but FortiManager was exploited as a zero-day in 2024 ("FortiJump").

- **FortiManager and FortiAnalyzer, pre-authentication:**
  - **CVE-2026-126170** (FG-IR-26-219, CVSS 9.8): JSON injection in the JSON-RPC API that gives code execution when the JSON API is enabled.
  - **CVE-2026-126261** (FG-IR-26-275, 9.0): an FGFM authorization flaw before the registration password is checked, reachable on **TCP 541**. Fixed in **FortiManager 8.0.1 / 7.6.8 / 7.4.6 / 7.2.9**.
  - **CVE-2026-126262** (FG-IR-26-276, 9.3): OFTP SQL injection leading to RCE, reachable on **TCP 514**.
  - **CVE-2026-126260** (9.0): OFTP server-side request forgery.
- **FortiOS routing:**
  - **CVE-2026-126253** (FG-IR-26-267, 9.3): an OSPF authentication bypass that allows forged LSAs. Fixed in **8.0.2 / 7.6.8 / 7.4.13 / 7.2.14**; FortiSASE customers need to migrate.
  - **CVE-2026-126254** (9.6): a BGP flaw that requires a configured iBGP neighbour.
- **Authenticated:** **CVE-2026-126229** (9.1) lets an admin reach other VDOMs.

**Action:**
- Upgrade FortiManager and FortiAnalyzer first.
- Make sure TCP 541 and 514 are reachable only from managed devices, never from the internet.
- Turn off the JSON API if you do not use it.
- Use Fortinet's upgrade tool to find the path on each branch.

Sources: [FortiGuard FG-IR-26-275](https://www.fortiguard.com/psirt/FG-IR-26-275), [FortiGuard FG-IR-26-267](https://www.fortiguard.com/psirt/FG-IR-26-267), [FortiGuard PSIRT](https://www.fortiguard.com/psirt), [Cyber Security News](https://cybersecuritynews.com/critical-fortinet-flaws-patched/), [GBHackers](https://gbhackers.com/critical-fortinet-vulnerabilities/)

### 1.5 SAP ICM2SHELL, PROXYGATE and SAML2 bypass: four CVSS 10.0 flaws (NEW)
- **The release:** SAP's November Patch Day covers **35** new notes (**42** including updates), **9** of them critical. Four are rated **10.0** and need no login.
- **ICM2SHELL:**
  - **CVE-2026-76964** (ICM, note **3778530**) and **CVE-2026-89126** (Web Dispatcher, note **3778556**).
  - Crafted WebSocket frames corrupt memory before login, giving code execution as `<sid>adm`.
  - Onapsis found it and gave SAP a working exploit.
- **PROXYGATE, CVE-2026-89103** (Gateway, note **3798345**): with the default ACL, an outside attacker can be treated as an internal application server.
- **CVE-2026-120017** (SAML2 SP, note **3849308**): in some configurations, assertion signatures are not checked, so an attacker can log in as any user. There is no workaround.
- **Status:** no exploitation reported. Out-of-maintenance kernels are affected and need upgrading.

**Action:**
- Patch every Web Dispatcher, including embedded and HANA XS ones. A single missed instance keeps the system exposed.
- Set `gw/acl_mode_proxy=1` or restrict `prxyinfo`. The kernel patch alone does not close the PROXYGATE exposure.
- Firewall gateway ports 33NN/48NN.
- Review trusted IdPs in transaction SAML2, and check logs for unexpected privileged SAML logons.

Sources: [The Hacker News](https://thehackernews.com/2026/11/sap-patches-four-cvss-100-flaws.html), [SecurityWeek](https://www.securityweek.com/sap-patches-critical-icm2shell-proxygate-vulnerabilities/), [BleepingComputer](https://www.bleepingcomputer.com/news/security/sap-patches-four-maximum-severity-security-vulnerabilities/)

## 4. Threat Watch
- **Turla "Cereal" on Exchange (ESET):**
  - **Attribution:** Turla (Secret Blizzard / Snake, assessed to be FSB Center 16).
  - **Tooling:** an eight-part .NET toolset on government Exchange servers in **Kazakhstan** (found **28 Nov 2025**) and **Romania** (compromised **23 Dec 2025**).
    - `CerealNeuron` is a passive backdoor listening on Exchange-like URL paths.
    - `CerealBox` is injected into `EdgeTransport.exe` and harvests mail with DOC/DOCX/PDF attachments matching sender, recipient or subject lists. In Romania it was set to collect NATO and EU correspondence.
    - There is **no external C2**: the Exchange server itself serves as the command channel.
  - **Hunt:** look for unexpected .NET assemblies loaded in EdgeTransport and for encrypted staging files. IOCs are in ESET's report.
  - [The Hacker News](https://thehackernews.com/2026/11/russian-turla-hackers-use-new-cereal.html), [Security Affairs](https://securityaffairs.com/202800/apt/russia-linked-apt-turla-turned-exchange-servers-into-their-own-control-room.html), [CyberScoop](https://cyberscoop.com/russian-turla-group-used-new-toolset-to-silently-pilfer-emails-from-kazakhstan-romanian-governments/)
