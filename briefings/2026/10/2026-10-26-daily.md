## 1. Risk Watch

### 1.1 PHP2Shell — unauthenticated PHP RCE (ONGOING)
Two PHP flaws, **CVE-2026-109618** (out-of-memory corruption) and **CVE-2026-109619** (stale global state after free), both **CVSS 4.0 9.2**, give unauthenticated RCE and worker-memory disclosure. Details leaked ahead of coordinated disclosure; fixes shipped 21 Oct in **PHP 8.5.12, 8.4.27, 8.3.36, 8.2.35**, with minimal source backports for 7.4/8.0/8.1. watchTowr and Cloudflare saw early exploitation attempts; Hadrian claims at-scale exploitation (vendors disagree on how many attempts succeed). CISA has advised all PHP-site operators to patch immediately; I found no confirmation of a KEV listing. Datadog notes that community mitigations such as `session.upload_progress.enabled=0` do **not** protect. Some posts cite CVSS 10.0, which came from an unofficial leak.
Action: Inventory web-facing PHP (php-fpm/Apache SAPI versions can differ from CLI), patch to the fixed versions or vendor backports, upgrade EOL branches, and hunt for new web shells and unexpected children of php-fpm/apache. Rotate secrets on hosts exposed unpatched since 20 Oct.
Sources: [SC World (CISA advice)](https://www.scworld.com/news/cisa-advises-orgs-to-patch-php2shell-bugs-immediately) · [SecurityWeek](https://www.securityweek.com/php2shell-patches-land-as-first-exploitation-attempts-hit-sensors/amp/) · [Datadog Security Labs](https://securitylabs.datadoghq.com/articles/php2shell-critical-vulnerabilities-in-php.md) · [Help Net Security](https://helpnetsecurity.com/2026/10/21/php2shell-php-vulnerabilities-patched-cve-2026-109618-cve-2026-109619) · [watchTowr](https://watchtowr.com/intelligence/php-remote-code-execution-php2shell/)

### 1.2 BeyondTrust Remote Support CVE-2026-102764 — China-nexus zero-day (follow-up)
Critical flaw (**CVSS 4.0 9.3**) in an internal messaging component; unauthenticated file operations on the appliance, affecting Remote Support up to **26.2.3**. GTIG attributes exploitation to **ARMORY CASTLE** (suspected PRC-nexus) from **29 Aug** until patch **BT26-05-RS** on 9 Oct (SaaS auto-patched). Post-exploitation: root via SUID, custom backdoors, credential harvesting. In CISA KEV since 16 Oct.
Action: Confirm the fix on self-hosted appliances; because exploitation predates the patch by ~6 weeks, review for unexpected SUID binaries/new files, rotate credentials the appliance handled, and review lateral movement from it.
Sources: [BeyondTrust BT26-05](https://beyondtrust.com/blog/entry/bt26-05) · [Cybersecurity Dive](https://www.cybersecuritydive.com/news/china-espionage-beyondtrust-zero-day-hacker/833240/) · [BleepingComputer](https://bleepingcomputer.com/news/security/beyondtrust-patches-zero-day-exploited-in-attacks-since-august)

### 1.3 FortiBleed — credential campaign against FortiGate / GlobalProtect (ONGOING)
FBI/USSS advisory (6 Oct): leaked credentials, infostealer logs, stuffing and spraying against edge VPN/firewall admin interfaces; SOCRadar counts **86,644 devices in 194 countries**. Attackers add their own admin accounts and sometimes lock owners out; **INC/Lynx** and **Payload** affiliates are named using this for initial access. Fortinet states it is **not a new vulnerability**.
Action: Audit admin accounts and recent config changes, reset admin/VPN credentials, enforce MFA, restrict management interfaces to allow-listed sources, and review VPN logs for spray patterns.
Sources: [FBI IC3 CSA](https://www.ic3.gov/CSA/2026/261006.pdf) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/fbi-ongoing-fortibleed-attacks-lock-out-fortigate-vpn-admins/amp/) · [Infosecurity](https://www.infosecurity-magazine.com/news/fbi-secret-service-fortibleed/)

### 1.4 Node.js Brotli decoder RCE CVE-2026-111497 (NEW to Risk Watch)
Out-of-bounds write in the Brotli decoder (**CVSS 9.2**, rated High by Node.js) can lead to code execution; also affects Bun, Python brotli/brotlicffi and Envoy per earlier reporting. Node.js security release of 21 Oct fixes ten CVEs: upgrade to **22.23.4, 24.22.1 or 26.12.1**. No workarounds; **Node 20 and older get no fix**. One summary warns that some articles cite different CVE numbers than the official Node.js page. A claimed Microsoft out-of-band .NET fix could not be confirmed.
Action: Upgrade Node runtimes (including those bundled in containers and Electron apps), migrate off Node 20, and check the official Node.js advisory for the authoritative CVE list. Prioritise services that decompress untrusted Brotli input (proxies, fetch clients).
Sources: [SecurityOnline](https://securityonline.info/nodejs-security-release-october-2026/) · [Konfirmity](https://www.konfirmity.com/advisories/nodejs-october-2026-security-releases) · [Cybernews](https://cybernews.com/security/php-node-js-vulnerabilities-patch-exploit/)
