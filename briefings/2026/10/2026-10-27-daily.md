## 1. Risk Watch

### 1.1 PHP2Shell — now reportedly in CISA KEV (ONGOING, escalated)
**CVE-2026-109618** (memory corruption) and **CVE-2026-109619** (stale internal request state), both **CVSS 4.0 9.2**, enable unauthenticated RCE. Fixed 21 Oct in **PHP 8.5.12, 8.4.27, 8.3.36, 8.2.35** (minimal backports for older branches). Search results indicate CISA's 26 Oct KEV alert lists both CVEs and updated its PHP alert; one tracker had shown "not listed" as of 23 Oct, so the listing is new. Exploitation: Amazon reports an attempt on **17 Oct**, four days before patches; Cloudflare reports thousands of attempts pre-disclosure and millions after; Recorded Future notes that successful compromise is not established, and German, Dutch and Japanese officials said they had seen no successful breaches. CYFIRMA assesses with moderate confidence that a DPRK/Lazarus-linked group is staging attacks (reported target set of 216 hosts, 21 low-volume scan nodes, activity back to **17 Oct**); this is planning/scanning evidence, not confirmed exploitation. Community mitigations such as `session.upload_progress.enabled=0` do not protect.
Action: Patch all web-facing PHP (check php-fpm/Apache SAPI versions, not just CLI) and upgrade EOL branches; hunt back to 17 Oct for new web shells, unexpected children of php-fpm/apache, and outbound connections from web workers; rotate secrets on hosts exposed unpatched.
Sources: [CISA KEV alert, 26 Oct](https://www.cisa.gov/news-events/alerts/2026/10/26/cisa-adds-two-known-exploited-vulnerabilities-catalog) · [CISA PHP alert](https://www.cisa.gov/news-events/alerts/2026/10/21/critical-vulnerabilities-php-require-immediate-patching) · [Recorded Future](https://www.recordedfuture.com/blog/php2shell-vulnerability-exploitation) · [BleepingComputer (Amazon)](https://www.bleepingcomputer.com/news/security/amazon-says-php2shell-exploitation-began-4-days-before-patches/amp/) · [CYFIRMA](https://www.cyfirma.com/research/cyfirma-threat-advisory-suspected-dprk-campaign-staging-php2shell-targeting-against-global-php-infrastructure/)

### 1.2 BeyondTrust Remote Support CVE-2026-102764 — China-nexus zero-day (follow-up)
**CVSS 4.0 9.3**, unauthenticated file operations on Remote Support up to **26.2.3**; exploited from **29 Aug** by suspected PRC-nexus **ARMORY CASTLE** until patch **BT26-05-RS** (9 Oct). In KEV since 16 Oct. No new developments found today.
Action: Confirm the patch on self-hosted appliances; because exploitation predated the fix by ~6 weeks, check for unexpected SUID binaries and new files, rotate credentials the appliance handled, and review lateral movement from it.
Sources: [BeyondTrust BT26-05](https://beyondtrust.com/blog/entry/bt26-05) · [Cybersecurity Dive](https://www.cybersecuritydive.com/news/china-espionage-beyondtrust-zero-day-hacker/833240/)

### 1.3 FortiBleed — credential campaign against FortiGate / GlobalProtect (ONGOING)
FBI/USSS advisory (6 Oct): leaked credentials, infostealer logs and spraying against edge VPN/firewall admin interfaces; SOCRadar counts **86,644 devices in 194 countries**. Attackers create their own admin accounts and may lock owners out; **INC/Lynx** and **Payload** affiliates named. Fortinet states it is not a new vulnerability. Check Point's 26 Oct report separately mentions a group ("k0t") exposing **70,000+** credentials via Fortinet and Palo Alto devices (secondary summary; unverified).
Action: Audit admin accounts and recent config changes, reset admin/VPN credentials, enforce MFA, restrict management interfaces, and review VPN logs for spray patterns.
Sources: [FBI IC3 CSA](https://www.ic3.gov/CSA/2026/261006.pdf) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/fbi-ongoing-fortibleed-attacks-lock-out-fortigate-vpn-admins/amp/) · [Check Point weekly, 26 Oct](https://research.checkpoint.com/2026/26th-october-threat-intelligence-report)

### 1.4 Node.js Brotli decoder RCE CVE-2026-111497 (follow-up)
Out-of-bounds write (**CVSS 9.2**) in the Brotli decoder; fixed in the 21 Oct security release (**22.23.4, 24.22.1, 26.12.1**). No workaround; **Node 20 and older get no fix**. Other Brotli consumers (Bun, Python brotli bindings, Envoy) were named in earlier reporting. CVE numbering differs between some articles and the official Node.js page.
Action: Upgrade Node (including containers and Electron bundles), plan migration off Node 20, prioritise services that decompress untrusted Brotli input, and check the official advisory for the authoritative CVE list.
Sources: [SecurityOnline](https://securityonline.info/nodejs-security-release-october-2026/) · [Cybernews](https://cybernews.com/security/php-node-js-vulnerabilities-patch-exploit/)
