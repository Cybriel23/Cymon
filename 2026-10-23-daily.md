## 1. Risk Watch

### 1.1 PHP critical RCE flaws, emergency patching (NEW, DEVELOPING)
Two flaws reported as **CVE-2026-109618** and **CVE-2026-109619** (each rated **9.2**) allow unauthenticated remote code execution and are said to affect PHP installations serving web requests. Fixes ship for supported branches **8.2 to 8.5**; unsupported versions may get none. The NSA advised patching immediately or taking systems offline until mitigated; sites in Finland, the Netherlands, Belgium and France were pulled offline or degraded, some as a precaution. Exploitation status conflicts: CISA said it had not observed exploitation at publication, while Cloudflare reports attack traffic and evasion attempts against customers (success not confirmed). The CVE numbering looks non-standard and I could not check NVD, so verify IDs against php.net. Reports of a flaw dating to 2024 and "AI-discovered" origin come from secondary outlets.
**Action:** Inventory every PHP runtime (web apps, CMS, containers, shared hosting), move to the latest 8.2 to 8.5 point release, upgrade or isolate EOL branches, put a WAF in front, and review web logs from 17 Oct onward for anomalous requests to PHP endpoints and new files in web roots.
Sources: [Defense One](https://www.defenseone.com/threats/2026/10/critical-flaws-php-warning/416727) · [The National](https://www.thenationalnews.com/future/technology/2026/10/21/php-version-vulnerability-critical-security/) · [The Standard (HK)](https://www.thestandard.com.hk/world/article/346131/PHP-developers-issue-updates-to-fix-vulnerabilities-says-flaw-was-found-in-2024) · [Cyprus Mail](https://cyprus-mail.com/2026/10/21/websites-down-worldwide-as-critical-cyber-security-update-issued)

### 1.2 Ivanti Connect Secure zero-day chain, root escalation unpatched (ONGOING, follow-up)
Volexity's **UTA0576** chained three zero-days against fully patched Connect Secure appliances for unauthenticated root command execution. The first two (auth bypass and RCE, **CVE-2026-104935**) are fixed in **22.8R2.5, 25.1.1.2, 25.1.3.0, 25.1.3.1**. The privilege-escalation link has no CVE or patch in any report I found; coverage says a fix is weeks away. Exploitation began about 1 to 3 Oct (possibly late September); no webshell is dropped, the actor re-exploits for each command and tampers with logs, and Ivanti's Integrity Checker Tool does not detect it. A French summary claims Aviatrix researchers saw a second undisclosed escalation; unverified.
**Action:** Apply the fixed builds, remove management and VPN portals from direct internet exposure where possible, preserve external logs/telemetry for forensics, and rotate secrets and certificates held on the appliance. Re-check Ivanti's advisory daily for the escalation fix.
Sources: [The Hacker News](https://thehackernews.com/2026/10/attacker-chains-three-ivanti-connect.html) · [BleepingComputer](https://bleepingcomputer.com/news/security/ivanti-warns-of-connect-secure-zero-day-exploited-in-attacks) · [iTnews](https://itnews.com.au/news/attackers-chain-three-ivanti-vpn-zero-days-for-root-access-629621) · [CSA research note](https://labs.cloudsecurityalliance.org/wp-content/uploads/2026/10/CSA_research_note_ivanti_connect_secure_zero_day_chain_20261016-csa-styled.pdf)

### 1.3 Plex2Shell exploitation and KEV deadline today (NEW, KEV)
CISA added four Plex Media Server flaws (**CVE-2026-96652, -96654, -96655, -96656**) to KEV on **20 Oct**. Researcher Zach Main showed they chain (SSRF and path-handling issues, one scored 8.6) into unauthenticated RCE with the owner's admin token. Exploitation began around **17 Oct**, first seen on honeypots, with cryptominers and proxy malware deployed. Federal deadline is **23 Oct**; fixed in **1.43.3.10861** (sources disagree whether released 3 or 4 Aug). Same-day KEV adds: Siemens Software Center **CVE-2026-110936** and EG Secure Solutions SiteGuard **CVE-2026-106931**. Plex servers on corporate or home-office networks are a quiet foothold risk.
**Action:** Update Plex to **1.43.3.10861** or later, remove public exposure, and hunt for unknown miners, proxy services and new admin tokens on any Plex host.
Sources: [The Hacker News](https://thehackernews.com/2026/10/cisa-orders-federal-agencies-to-patch.html) · [BleepingComputer](https://bleepingcomputer.com/news/security/cisa-hackers-chain-plex-flaws-in-plex2shell-attacks-to-breach-servers) · [CISA alert](https://www.cisa.gov/news-events/alerts/2026/10/20/cisa-adds-six-known-exploited-vulnerabilities-catalog)

### 1.4 FortiBleed credential campaign against FortiGate SSL VPN (ONGOING)
The FBI and Secret Service (advisory dated **6 Oct**) say FortiBleed remains active: credential stuffing and spraying using leaked Fortinet dumps and infostealer logs, offline cracking of stolen hashes, then creation of rogue admin accounts and deletion of legitimate admins (lockouts). SOCRadar counts **86,644+** compromised device credentials across 194 countries (as of 19 June). Initial access for ransomware affiliates, with INC/Lynx and Payload named. Fortinet says it is credential reuse, not a new vulnerability. Pairs with last week's PEERSTITCH/FortiManager activity.
**Action:** Reset admin and VPN passwords, enforce phishing-resistant MFA, terminate active SSL VPN/admin sessions, review and revoke REST API keys (they survive password changes), and audit for unfamiliar admin accounts.
Sources: [The Hacker News](https://thehackernews.com/2026/10/fbi-warns-fortibleed-remains-active.html) · [BleepingComputer](https://bleepingcomputer.com/news/security/fbi-ongoing-fortibleed-attacks-lock-out-fortigate-vpn-admins) · [The Record](https://therecord.media/fortibleed-warning-fbi-secret-service)

### 1.5 ConnectWise Cloud Backup (SkyKick) credential abuse (DEVELOPING, follow-up)
Still suspended. Unauthorized sign-ins to Microsoft 365 tenants via Cloud Backup application identities from **15 Oct** (Huntress counted about 173 tenants); ConnectWise disabled identities and revoked certificates on 17 Oct. No root cause, attribution or restoration date has been published; ConnectWise says archives are intact and it has seen no further successful activity since mitigation, with an external forensics firm engaged. Sources disagree on the first detection date (14 vs 15 Oct).
**Action:** Review Entra sign-in and audit logs from 14 Oct for the ConnectWise/SkyKick enterprise apps (retention is only 7 days on free plans, so export now), revoke refresh tokens, hunt for unusual Graph mail/SharePoint access, and set up alternative backups.
Sources: [Huntress](https://www.huntress.com/blog/vendor-credential-enables-unauthorized-access) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-breach-microsoft-365-tenants-via-connectwise-supply-chain-attack/amp/) · [Techzine](https://www.techzine.eu/news/security/145071/connectwise-shuts-down-cloud-backup-after-hack-on-microsoft-365-tenants/)
